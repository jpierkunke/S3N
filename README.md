# Estimation and prediction with scalable spatial stream network (S3N) models

This code is built upon the [BRISC](https://github.com/ArkajyotiSaha/BRISC) package, extending it for spatial processes on stream networks.

To install this package, install the `remotes` package and then use the `install_github` function:

```{r}
install.packages("remotes") # if you don't already have the remotes package
remotes::install_github("jpierkunke/S3N")
```
